# Améliorations ergonomiques pour l'application de comparaison d'images

## 1. Raccourcis clavier

Implémenter des raccourcis clavier pour les actions fréquentes :

| Action | Raccourci |
|--------|-----------|
| Ouvrir Image 1 | Ctrl+1 |
| Ouvrir Image 2 | Ctrl+2 |
| Mode côte à côte | Ctrl+S |
| Mode curseur | Ctrl+L |
| Mode A/B Switch | Ctrl+A |
| Zoom avant | Ctrl++ |
| Zoom arrière | Ctrl+- |
| Réinitialiser le zoom | Ctrl+0 |
| Copier la vue actuelle | Ctrl+C |
| Quitter | Ctrl+Q |

## 2. Fonctionnalité de fichiers récents

- Ajouter un menu "Fichiers récents" qui garde en mémoire les dernières images ouvertes
- Permettre de charger rapidement des paires d'images précédemment comparées
- Stocker les chemins dans un fichier de configuration persistant

## 3. Retours visuels améliorés

- Ajouter des animations subtiles lors des transitions entre modes
- Mettre en surbrillance les zones de différence entre les images
- Afficher un indicateur de progression lors du chargement d'images volumineuses
- Ajouter des info-bulles (tooltips) détaillées pour chaque contrôle

## 4. Améliorations de l'interface de glisser-déposer

- Permettre le glisser-déposer d'images directement dans les zones de visualisation
- Afficher une zone cible visuelle lors du glisser-déposer
- Supporter le glisser-déposer de plusieurs fichiers à la fois

## 5. Personnalisation de l'interface

- Permettre à l'utilisateur de réorganiser les panneaux selon ses préférences
- Offrir plusieurs thèmes de couleurs (clair, sombre, contraste élevé)
- Mémoriser la disposition et les préférences entre les sessions

## 6. Aide contextuelle

- Ajouter un bouton d'aide (?) à côté des fonctionnalités complexes
- Afficher des bulles d'aide qui expliquent chaque fonctionnalité
- Intégrer un guide utilisateur accessible depuis le menu Aide

## 7. Barre d'état améliorée

- Afficher les coordonnées du curseur sur l'image
- Montrer les valeurs RGB du pixel sous le curseur
- Indiquer le niveau de zoom actuel
- Afficher les dimensions des images et leur ratio

## 8. Navigation améliorée

- Ajouter des boutons de navigation rapide (premier/dernier fichier du dossier)
- Permettre de parcourir les images d'un dossier avec les touches fléchées
- Ajouter un explorateur de miniatures pour les images du dossier courant
